# План «Творец»: последние дополнения проекта / The Creator plan: the project's last additions

Дата: 2026-11-08. База: `integration/beta12-all` после выпуска Beta 21 (`dc743de`, main `faf4082`). Одобрен владельцем в чате словами «как ты описал, всё правильно, давай начинать».

## Зачем

Владелец идёт по пути Творца: Python → математика → машинное обучение → своя языковая модель → улучшение моделей → AGI → сознание. Приложение должно вести по одному этому пути, а весь Mac становится мастерской Творца: инструменты, агенты, заметки и ассистент служат одной цели. Знания всегда достоверные, свежие, понятные, с практикой.

## Решения владельца

- Имя в окне, Finder и Dock: **«Творец»** (EN «Creator»). Файл `ColiDev.app`, bundle id, папка данных и служба Keychain не меняются.
- Главный экран: **«Путь Творца — становление Творцом»** и одна карточка «Твой следующий шаг».
- Лишние предметы (зоология, химия, физика, биология) прятать, не удалять; вернуть галочкой в настройках. Английский остаётся: статьи по ИИ на английском. **Инструменты не прятать никогда.**
- Ассистент: полный доступ к файлам, программам и Терминалу пользователя. Команды с `sudo` спрашивают пароль у самого владельца через окно macOS; пароль никто не вводит за него. Удаление, отправка, установка и изменение системных настроек выполняются после подтверждения владельца в окне ассистента.
- Голос: встроенное распознавание речи macOS на устройстве (SpeechAnalyzer на macOS 26+, иначе SFSpeechRecognizer), ответ голосом системы по-русски. Whisper не использовать: у владельца он работал рывками.
- Модели: гибрид. Локальные Ollama по умолчанию (бесплатно и без лимита), бесплатные облачные квоты (Gemini, бесплатные модели OpenRouter), подписка Claude через `claude -p`. Платные вызовы API только если владелец сам включит и задаст месячный потолок; по умолчанию выключено.
- Skillbox: курс на аккаунте владельца. Владелец сам входит во встроенном браузере, сессия читает только названия тем для списка с галочками и ссылками. Уроки Skillbox не копируются.

## Что делает владелец

1. Входит в Skillbox во встроенном браузере Claude, когда его попросят.
2. Даёт macOS разрешения на микрофон, распознавание речи и управление компьютером для «Творца», когда появится окно.
3. Нажимает «Всегда разрешать» в окне Связки ключей после новой сборки backend.
4. Решает, включать ли платные вызовы API и с каким потолком.

## Правила для сессий

Как в `CLAUDE.md` и `project-plan/HANDOFF_RU.md`: тексты RU/EN, тесты сразу, тренажёры на LabKit без готового ответа на старте, не ломать работающее, ключи и пароли не читать и не вводить, ничего не устанавливать без «да» владельца, платных вызовов нет. Отчитываться коротко простым русским: что сделано, что проверено запуском, что нет.
